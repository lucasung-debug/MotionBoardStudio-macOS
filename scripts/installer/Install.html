MotionBoard Studio

0.3.2 · Mac 빌드 3 · Apple Silicon · macOS 14 이상

설치

  1. 이 디스크의 MotionBoard Studio.app을 옆의 Applications 폴더로 드래그하세요.
  2. 복사가 끝나면 디스크를 추출하고, 응용 프로그램 폴더에서 MotionBoard Studio를 여세요.
  3. 앱 상단에서 ChatGPT 또는 Claude에 로그인하세요. 보드 이미지 자동 생성에는 ChatGPT 로그인이 필요합니다.

Node.js와 FFmpeg가 포함되어 있습니다. 별도의 개발 도구나 Homebrew 설치가 필요하지 않습니다. AI 생성과 음악 다운로드에는 인터넷 연결 및 사용할 서비스의 계정이 필요합니다.

처음 열 때 macOS가 실행을 막는 경우

이 배포본은 임시 서명을 사용하며 Apple 공증을 받지 않았습니다. 출처를 확인한 후 앱 실행을 한 번 시도하고, 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기에서 허용하세요.

Apple의 앱 열기 안내

생성 결과와 계정

기록은 사용자별 Application Support 폴더에, 로그인 정보는 macOS 키체인에 저장됩니다. 설치 파일에는 제작자의 계정, 생성 기록, 이미지, 음악 파일이 들어 있지 않습니다.

현재 영상 기능은 명세와 보드의 색·문구를 참고하는 모션 그래픽입니다. 보드 속 인물 자체를 움직이는 AI 영상 생성은 이 버전에 포함되지 않습니다.

오픈소스

앱 소스는 MIT 라이선스입니다. 포함된 Node.js와 FFmpeg에는 각각의 라이선스가 적용됩니다. FFmpeg의 정확한 소스와 빌드 방법도 앱 안에 포함되어 있습니다.
